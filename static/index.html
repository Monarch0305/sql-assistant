SQL behind the scenes.
Clarity up front.

The model proposes a query; Python checks and runs it with read-only database access. The answer is grounded in the returned rows.

01

Ask in plain English

Start with a question about the sample music store, such as top artists or sales by country.

03

Review the explanation

Get a concise answer with the SQL available to inspect. Check the result before using it to make a decision.

Where this can go

From sample data to business data.

The longer-term goal is to connect to business databases directly, so teams can explore their own information and use evidence to inform decisions. That requires careful access controls, database-specific setup, and stronger evaluation.
